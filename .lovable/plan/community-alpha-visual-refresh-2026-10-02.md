# Community Alpha visual refresh

## Goal
Bring `/community-alpha` into the same visual language as Daily Briefing and Alerts while preserving every existing interaction, data path, permission rule, and mobile behavior.

## Main visual changes
- Add the standard Terminus page heading treatment used by Daily Briefing and Alerts, with the existing Live/Staging control presented in the established compact tab style.
- Restyle search as a Terminus toolbar control using the shared input, icon-button, border, focus, and spacing patterns.
- Reframe the week selector as a compact navigation panel: institutional labels, active accent bar/state, tabular counts, and the existing horizontal mobile scroller.
- Apply the existing `hud-panel` card language to idea entries and utility areas, with tighter Terminus spacing and typography rather than the standalone reference-page treatment.
- Match Terminus headings, eyebrow labels, mono data text, controls, pills, dividers, empty/loading/error states, and light/dark theme tokens.
- Keep long/bullish/buy green, short/bearish red, exit/warning amber, and preserve the Technical tag as a distinct neutral status.
- Keep the staging banner prominent but align it with Terminus warning/status styling.
- Preserve the current desktop split and phone flow, including the Terminus mobile menu and horizontal week list.

## Implementation
1. Refine the React shell around the digest with existing Terminus building blocks such as `PageHeader`, `Button`, `Input`, `Tabs`, and Lucide icons where they can replace bespoke controls without changing behavior or refs. These shared components will only be imported and used; their files will not be modified.
2. Preserve the dashboard port's DOM hooks exactly: the search input remains `id="search"`, its clear control remains `id="search-clear"`, and their existing refs remain attached so search, `/`, Esc, and Close continue to work. The Live/Staging control is React-controlled and currently has no dashboard-port ID; its existing mode state, click handlers, `aria-pressed` values, and banner behavior will remain unchanged while only its presentation changes.
3. Restyle the HTML generated by the verbatim dashboard port through its scoped stylesheet only. Map generated cards, pills, buttons, ticker controls, tags, search results, and states to the same semantic tokens and visual patterns used by Daily Briefing and Alerts.
4. Leave `communityAlphaDashboard.ts` unchanged so search, week selection, top-ticker filtering, technical filtering, links, and rendering behavior remain the verbatim reference port.
5. Update the Community Alpha architecture rule to say explicitly: the dashboard logic stays a verbatim port of the reference, but the styling follows Terminus's design system.
6. Verify light and dark themes at desktop and phone widths. Exercise typed search, `/` focus, Esc clear/close, the Close control, Technical toggle, week selection, lookback and top-ticker controls, Live/Staging and its banner, valid Slack links, and the Terminus mobile menu. Confirm no overlap, clipping, or scroll regressions.

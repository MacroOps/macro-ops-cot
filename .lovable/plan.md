# Community Alpha visual refresh

## Goal
Bring `/community-alpha` into the same visual language as Daily Briefing and Alerts while preserving every existing interaction, data path, permission rule, and mobile behavior.

## Main visual changes
- Add the standard Terminus page heading treatment used by Daily Briefing and Alerts, with the existing Live/Staging control presented in the established compact tab style.
- Restyle search as a Terminus toolbar control using the shared input, icon-button, border, focus, and spacing patterns.
- Reframe the week selector as a compact navigation panel: institutional labels, active accent bar/state, tabular counts, and the existing horizontal mobile scroller.
- Apply the existing `hud-panel` card language to idea entries and utility areas, with tighter Terminus spacing and typography rather than the standalone reference-page treatment.
- Match Terminus headings, eyebrow labels, mono data text, controls, pills, dividers, empty/loading/error states, and light/dark theme tokens.
- Keep long/bullish/buy green, short/bearish red, exit/warning amber, and preserve the Technical tag as a distinct neutral status.
- Keep the staging banner prominent but align it with Terminus warning/status styling.
- Preserve the current desktop split and phone flow, including the Terminus mobile menu and horizontal week list.

## Implementation
1. Refine the React shell around the digest with existing Terminus building blocks such as `PageHeader`, `Button`, `Input`, `Tabs`, and Lucide icons where they can replace bespoke controls without changing behavior or refs.
2. Restyle the HTML generated by the verbatim dashboard port through its scoped stylesheet only. Map generated cards, pills, buttons, ticker controls, tags, search results, and states to the same semantic tokens and visual patterns used by Daily Briefing and Alerts.
3. Leave `communityAlphaDashboard.ts` unchanged so search, week selection, top-ticker filtering, technical filtering, links, and rendering behavior remain the verbatim reference port.
4. Update the Community Alpha architecture rule to state that dashboard behavior remains a verbatim port while styling follows the Terminus design system.
5. Verify light and dark themes at desktop and phone widths. Exercise Live/Staging, search and clear, week selection, lookback/top tickers, Technical toggle, valid Slack links, loading/error/empty states, and the mobile menu. Confirm no overlap, clipping, or scroll regressions.
